# UI Evidence Rules

**Match The Medium To The Change**:

- Use a screenshot when the result is a state that stays put, such as layout, colour, or copy.
- Use a video when the result happens over time, such as an animation, gesture, transition, or drag.

**Show It As It Is**:

- Keep enough of the screen in view to see what changed.
- Make the input visible, such as the cursor or touch indicators, when the interaction is the point.
